Receive mail. Keep your address. Choose a custom name, open the inbox, and leave no account behind.

Fast, Passwordless Temporary Mailboxes

TMail provides instant address-scoped inboxes with custom domain support, real-time message delivery, and automatic verification code extraction for testing and privacy.

  • No Registration Required: Open any available address immediately without passwords or signups.
  • Instant Verification Codes: Automatically extracts OTP codes and confirmation links directly in the message overview.
  • Multi-Domain Receiving: Backed by Postfix MX routing and Stalwart JMAP mail delivery.
  • Developer REST API: Stream incoming messages via Server-Sent Events (SSE) and download RFC 822 sources programmatically.

How It Works

  1. Choose or generate an address: Select any recipient prefix and receiving domain.
  2. Receive emails in real-time: Incoming emails appear with instant notifications and audio alerts.
  3. Automatic cleanup: Inboxes and messages expire safely based on server retention policy.
